# My-personal-page

这是我在 Vibe Coding 的第一个项目 —— 一张“唱片式”的个人名片。打开页面先看到一张深蓝色的唱片封皮,点一下封皮,唱片会从封皮套里钻出来、再和封皮一起挪到左边旋转,右边露出我的个人信息。整个过程有点像拆一张老黑胶。

整个项目只有一个 index.html 文件,样式写在 style 标签里,脚本写在 script 标签里,没有用任何框架、外部库、外部图片或字体,双击就能打开看。

## 如何运行

不用安装任何东西,也不用起服务器。

1. 把仓库克隆到本地。
2. 进入项目文件夹。
3. 双击 index.html,用浏览器打开即可。

如果想在手机上看效果,可以把 index.html 用微信或邮件发给自己,在手机浏览器里打开,页面会自动切到上下布局。

## 已完成功能

下面这些是我已经在这个页面里实现的东西,都从 index.html 里能找到对应代码。

- 个人信息展示:昵称「芋泥」、一句话介绍「在数字与文字间,寻找独一无二符号的旅行家」、三个兴趣标签(弹钢琴、唱歌、旅行)。
- 唱片主题封皮:纯 CSS 画的正方形封面,包含深蓝渐变底色、十颗星点、顶部全息镭射条、八个月相图标、五条彩虹弧线、外发光层、一个小新月、底部标题「Personal Page」和副标题「MIDNIGHTS · YUNI EDITION」。
- 唱片本体:深灰到浅蓝的径向渐变 + 同心圆纹理,中心一个白色圆形标签,上面写着「yuni」。
- 三阶段开盒动画:
  - 阶段一:点击封皮后,唱片从封皮套内向右滑出,这一阶段不旋转。
  - 阶段二:大约 1 秒后,封皮和唱片一起向左移动,唱片叠在封皮上方,开始整体匀速旋转(6.5 秒一圈),右侧个人信息卡片淡入。
  - 阶段三:点「重置动画」按钮,可以把动画倒回去再看一次。
- 日夜模式切换:右上角按钮,日间是浅蓝雾霾渐变背景,带有波光闪烁动效;夜间是深蓝层叠渐变背景,顶部有暖色余晖柔光环。切换时两层背景交叉淡入淡出,按钮文字在「切换夜间模式」和「切换日间模式」之间同步变化。
- 动态 rem 自适应:脚本会根据窗口宽度动态设置根字号(以 1920 设计稿为基准,1rem 等于 100px),并监听 resize 和 pageshow 事件,带上下限保护,缩放浏览器时整体等比放大缩小,不会出现"只上移不缩放"的问题。
- 三档响应式布局:桌面端(宽度大于等于 1024px)左右布局;平板端(768 到 1023px)仍是左右布局但封皮略缩小;手机端(小于 768px)改为上下布局,封皮在上、信息卡在下,唱片移出方向也改成向下,避免横向滚动。
- 全部尺寸用 rem,字号也用 rem,布局用 Flexbox,没有写死固定像素宽度。
- 单文件交付:只有 index.html 一个文件,CSS 和 JS 全部内嵌,不依赖任何外部资源。

## 我的探索
由于平时自己喜欢听音乐，所以个人页面也选择了唱片主题。然而，让AI做出我满意的唱片动画效果也成为了该项目最耗时的部分，我需要不断调整提示词并配以参考图。但这一步也提高了我写提示词的能力，从最初的只简单说“让唱片从封皮套中旋转而出”到能够细致分点写出我希望的动画效果，我意识到撰写好的提示词在vibe coding中的重要性。

## 遇到的问题
1.唱片动画效果提示词的优化。为达到理想的动画效果，我前后修改调整了6次提示词。比如，唱片一开始是从封皮上方滑出来的而不是封皮内部。又如，唱片一开始大于封皮套。每次AI给出结果后，我都按照先定位后修改的方法，不断促使AI生成结果迭代。
2.网页如何正常缩放。在初版生成后，我发现在我缩放网页时，我的页面无法自适应页面变化。对此我直接抛给AI“使页面等比例整体缩放”的要求，但结果并不好。但我作为文科生，并不知道相关术语是什么，因此我单独打开了deepseek页面，把我的需求告诉它，它又为我撰写了有技术要求的提示词，我复制给Trae，从而达到理想的效果，可见AI交互使用的重要性。
